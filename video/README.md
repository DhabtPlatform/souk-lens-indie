## What is in the film

- **01 The Problem** — one real stall, zero listings; a **3 × 2 SAM 3.1 live-box map** in neon.
- **02 Capture** — phone-camera capture, shutter, “CAPTURED”.
- **03 Analyze / Catalog** — the live Products page, then neon camera zooms + arrows labelled **SAM 3.1**, **Muse Spark 1.3**, and **Muse Image 1.0** across masks, title/description/price, variants, and field traceability.
- **04 The Relay** — four models, one schema; the same photo passes through SAM → Spark → Muse Image → Meta Voice, with the real 3 × 2 mask layout.
- **05 Voice + Text** — voice transcript → generated listing, one-sentence text → variants + studio image, each event labelled with its model.
- **06 Link + Store** — URL → local-price listing and store import → 191 listings / ×62, with model-labelled focus passes.
- **07 Buyer Agent** — Smart Market 3 baskets, 1,511 total / 404 saved, then the **real preliminary invoice** (`Best match & quality`: 1,356 subtotal, −404 savings, 155 shipping, 1,511 total).
- **08 Geo** — country, currency, and language detected automatically across six markets.
- **09 Rigor** — every metric is a measured run; every field editable and traceable.
- **10 Vision** — photographed, grounded, verified → giant brand tagline → end card with **SOUK LENS**, **Meta**, and the four model names in neon.
